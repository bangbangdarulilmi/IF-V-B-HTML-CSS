Introduction to HTML

HTML (HyperText Markup Language) is the standard language used to create and structure content on the web.

HTML uses elements and tags to define headings, paragraphs, images, links, tables, and other web content.

Key Points

  • HTML stands for HyperText Markup Language.
  • HTML provides the structure of a webpage.
  • HTML uses tags to define elements.
  • HTML works together with CSS and JavaScript.

HTML Code Example

Here is a simple example of an HTML document: 

<!DOCTYPE html>
<html lang="en">
<head>
    <title>My First Page</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>Welcome to HTML.</p>
</body>
</html>

Common HTML Tags

The following table contains some commonly used HTML tags.

Tag Description Example
<h1> Defines a main heading. <h1>Title</h1>
<p> Defines a paragraph. <p>Hello</p>
<a> Creates a hyperlink. <a href="#">Link</a>
<img> Displays an image. <img src="image.jpg" alt="Image">
<ul> Creates an unordered list. <ul>...</ul>
<table> Creates a table. <table>...</table>
