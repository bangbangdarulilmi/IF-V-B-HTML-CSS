Introduction to HTML

HTML stands for HyperText Markup Language. HTML is the standard markup language used to create web pages.

HTML describes the structure of a web page using elements represented by tags.

Key Points

  • HTML stands for HyperText Markup Language.
  • HTML is used to structure web pages.
  • HTML elements are represented by tags.
  • HTML works together with CSS and JavaScript.

Why Learn HTML?

HTML is the foundation of web development. By learning HTML, you can create the basic structure of a website.

  • Create headings and paragraphs.
  • Add images and links.
  • Create tables and forms.

HTML Code Example

The following example shows the basic structure of an HTML document.

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>My First Page</title> </head> <body> <h1>Hello World!</h1> <p>This is my first HTML page.</p> </body> </html>

Common HTML Tags

Tag Function Example
<h1> Creates a heading. <h1>Title</h1>
<p> Creates a paragraph. <p>Hello</p>
<a> Creates a hyperlink. <a href="url">Link</a>
<img> Displays an image. <img src="image.jpg" alt="Image">
<ul> Creates an unordered list. <ul>...</ul>
<form> Creates a form. <form>...</form>
